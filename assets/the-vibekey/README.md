# the Vibekey icon

Original artwork for this fork: a rounded ivory V, an elliptical orbit and three small colored markers on a dark teal tile. No upstream icon, third-party asset or font was used. Colors: teal #102C32–#355B60, ivory #E9F3EC; markers #A8CDC2 / #D3DEC3 / #839DE1. Licensed under the repository MIT license.

The canonical vector drawing is `scripts/make-brand-icon.swift`; TheVibekey.png is its 1024px render and AppIcon.icns contains the native icon sizes. The generated .iconset directory is ignored. Render instructions are in THE-VIBEKEY.md.
