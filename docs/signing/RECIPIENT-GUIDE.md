# 安装开发者个人代码签名证书

v1公开证书包已生成，真实指纹与有效期以包内manifest和fingerprint文件为准，并须通过开发者确认的渠道核对。接收者Mac界面步骤仍待独立验收；本文不代表已完成跨Mac测试。

这张证书用于识别开发者签署的软件。导入后还需明确设置代码签名信任；它不授予软件访问聊天、键盘、麦克风或文件的权限，也不保证自动通过Gatekeeper。

## 安装前核验

向开发者核对证书公开名称、有效期、SHA-256指纹。用已确认的沟通渠道核对，不只相信文件名或同目录说明。接收包应仅含公开证书和文档；不需要任何私钥或P12。

## 安装

1. 双击公开 `.cer` 文件，选择自己的“登录”钥匙串。
2. 在“钥匙串访问”中核对该证书的SHA-256指纹和用途。
3. 在信任设置中，仅明确允许“代码签名”用途；其他用途保持系统默认。不同macOS版本的文字可能不同，实际步骤须在接收者验收后补齐。
4. 若系统要求登录密码，由你本人输入。开发者及安装器不应收集密码。
5. 安装App。系统仍可能要求逐App首次运行确认，或授权辅助功能、输入监控等。不要把安装证书当作已完成这些步骤。

## 取消信任

在自己的登录钥匙串中，按开发者确认的指纹找到证书，取消该项代码签名信任或移除该证书。不要删除其他证书。已经放行的程序如何运行取决于系统和其他策略，不承诺仅移除证书就终止或阻止所有已有App。

遇到名称或指纹不符、证书过期、系统仍拒绝打开时，停下并反馈实际提示；不要自行关闭全局安全保护。第一次安装流程要在独立Mac/干净账户上验收后才能作为正式用户文档发布。
